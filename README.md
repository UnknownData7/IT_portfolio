## MTC True Tech | Changellenge Cup IT 2026: «Выше крыши»

**Задача.** МТС предоставила два источника геоданных о зданиях Санкт-Петербурга. Нужно было объединить их в единый достоверный слой высотности, пригодный для планирования сети базовых станций.

**Решение:**
1. **Очистка и объединение источников.** Здания из разных источников сопоставляли через `cKDTree` и индекс Жаккара (IoU ≥ 0.1), а случаи many-to-many разбирали через граф связности. Получился датасет из 155 439 зданий с 69 признаками.
2. **ML-модель высоты.** Для 16.6% зданий без высоты обучили LightGBM со Spatial Split, чтобы избежать утечки данных между соседними объектами.
3. **Аналитика.** Анализ высотности по типам зданий и районам, сеточный анализ 500×500 м с тепловыми картами, поиск блокировщиков сигнала. Кластеризация города на 3 зоны качества покрытия по индексу сложности на основе Mutual Information.
4. **Визуализация.** Интерактивная карта на kepler.gl

**Результаты:**

| Метрика | Значение |
|---|---|
| Зданий в финальном датасете | 155 439 |
| Полнота данных о высоте | 83.4% → 100% |
| Восстановлено ML | 25 832 здания (16.6%) |
| MAE / RMSE / R² модели | ~2.3 м / ~3.1 м / ~0.94 |
| Блокировщики сигнала (>20 м) | 29 213 (18.8%) |
| Зона C, сложное покрытие | 22 969 зданий (14.8%) |

**Моя роль: Data Analyst.** Вместе с Григорием Бондаренко создал аналитический ноутбук по датасету после ML-модели, разработал фичу кластеризации города на зоны по индексу сложности покрытия, подготовил устную часть выступления и выступал спикером на защите.

## ВТБ х Башни: Universal PostgreSQL Migration Tool

Инструмент для миграции данных между базами PostgreSQL с разными стратегиями и автоматическим анализом зависимостей.

**Возможности:**
- четыре режима миграции: `full`, `upsert`, `incremental`, `append`;
- автоматический анализ foreign key и загрузка таблиц в правильном порядке (топологическая сортировка);
- параллельная миграция с прогресс-баром;
- валидация результатов и dry-run режим;
- логирование, обработка ошибок, транзакции и откат.

**Быстрый старт:**

```bash
docker-compose up -d
./main.sh config/upsert.conf 4
./utils/check_target.sh
```
